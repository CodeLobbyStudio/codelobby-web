# Team design — static milestone

The initial visual foundation follows the team reference: a dark navy background,
orange accents, CodeLobby branding, a responsive header/footer, a hero headline,
feature summaries, four workflow cards and an instructor illustration.

The inline lobby illustration shows task text, sample Python code, test results,
participants and ranking as static visual content. It does not represent an active
session. Controls remain inactive, including account navigation and section links.

This is an incremental delivery of web #4. Expanded previews, interactive tabs and
section navigation are planned for a later change. Authentication and real lobby
operations belong to their separate issues.

Do not publish changes or open a PR without the user's explicit approval.
